# Game Development
Made a pong game using pygame. Followed the video tutorial step by step and made some personal additions as well:
  1. Storing both the scores and the winner's name in the end of the match of 10 points.
  2. Increasing ball speed after each successful hit.
  3. Code contains implementation of both 2 player mode and Player vs. AI mode. To change any player into AI, In the code, do "AI = True".
